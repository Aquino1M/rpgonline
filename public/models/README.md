# Modelos 3D opcionais

O jogo funciona sem nenhum arquivo externo: personagem, NPCs, montaria, mobs, casas e props possuem fallback procedural 3D.

Se você tiver licença para redistribuir modelos GLB/GLTF, coloque-os aqui com estes nomes:

- `player.glb` — personagem humano principal (rig/animations opcionais)
- `mount.glb` — montaria
- `wolf.glb` — mobs do tipo lobo
- `dragon.glb` — mobs/bosses do tipo dragão

A V0.4 tenta carregar os arquivos automaticamente e mantém o fallback procedural quando não existem.

## Free3D

Não inclua no GitHub um modelo cujo anúncio esteja marcado somente como **Personal Use License** sem uma autorização adicional que permita redistribuição. O fato de o download ser gratuito não significa automaticamente que o arquivo possa ser republicado dentro de um repositório público.

Se você tiver uma licença/autorização compatível de um modelo do Free3D, converta para `.glb` (Blender: File > Export > glTF 2.0) e use os nomes acima.
